The answer pipeline

Scope
Rules match the company (names, aliases, tickers) and fiscal period, using FinanceBench's period labels and a one-year lookback for forecasts. No company found means a polite refusal and no model call.
Route
A rules router decides whether a question needs computed facts, retrieved prose, or both. Fact questions get a Facts section ahead of the excerpts.
Chunking
structured@1: table-preserving chunks, each prefixed with a header line naming the company, form, period, Item and heading, so a table of numbers still embeds near a question asked in words.
Retrieve
An exact scan over only the scoped filings (hundreds to a few thousand vectors), top 50 by cosine similarity, then Voyage rerank-3 keeps 10. Hybrid BM25 was tried and didn't help.
Generate
Claude Sonnet 5.5 with answer@4: answer only from the Facts and Excerpts, cite each one, and say so when the evidence is missing.

What 87.3% means

131 of the 150 questions in FinanceBench's open subset were answered correctly. Each question is about a real SEC filing and comes with an answer written by an analyst. Run 846 is the same pipeline this site runs.

1. Answer
The pipeline above answers each question. It searches all 367 filings, not just the one a question is about, so finding the right document is part of the test.
2. Grade
Claude Opus 5.5 compares the answer with the analyst's. Numbers must match at the analyst's precision (about 1% leeway on computed ratios), for the same period and units. An answer that hedges between two numbers is wrong.
3. Count
Anything not graded correct counts against it. Of the 19 misses, 18 were wrong answers and 1 was a refusal.

How much to trust it

  • Stable: three runs with nothing changed scored 87.3%, 86.7% and 86.7%; grading the same answers three times gave identical verdicts.
  • A small sample: with 150 questions the 95% interval is about 81–92%, so the 84% scores for other answer models aren't clearly worse.
  • A model grades it: the few verdicts that flip between runs sit on debatable gold answers, such as $0.389B against $0.40B.
  • Open subset only: not comparable with full FinanceBench results.

What it doesn't measure

How well this site answers your questions. Visitors ask different things than a benchmark, and questions outside the 32 companies are refused rather than answered. That's why a thumbs-down here can become a test case that a run reproduces.

How it got to 87.3%

FinanceBench open subset, 150 questions; these are not full-set results. Answers are judged by Claude Opus 5.5 against a pinned rubric. The corpus is the 84 filings the questions cite plus 283 distractor filings from the same companies.

Evals as infrastructure

  • Re-running the best config moves accuracy by about one question, so CI gates on retrieval (recall@10, MRR), which embedding and rerank caches make exact.
  • The gate blocked a deliberately bad chunker: recall@10 0.833 → 0.584.
  • Fiscal-period and faithfulness metrics; two synthetic question sets kept apart from the headline.
  • A thumbs-down on this site can become a case in a separate prod-feedback@1 set that a run reproduces.

Where it runs

Guardrails

10 questions per visitor per hour, a $3/day spend cap (reserve, then settle), 500-character questions, 3 at a time.

Privacy

Visitor addresses are salted and hashed for rate limiting; raw IPs are never stored or logged.

Deploys

Terraform for everything. GitHub Actions builds an arm64 image to ECR over OIDC and deploys by commit SHA through SSM; no SSH port.

Recovery

Daily backups of app data to S3 with a tested restore drill; CloudWatch alarms recover or reboot the instance.
